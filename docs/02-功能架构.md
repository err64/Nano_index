# 02 网站功能架构与信息架构

> Veriforge 官方网站 · 架构设计文档 · 2026-10-06

## 1. 站点地图

```
/                       首页        品牌形象、核心价值、能力总览、新闻速览、转化 CTA
/project/               项目介绍    项目背景、发展历程、核心优势对照
/products/              产品与服务  核心功能详解（五大子系统）、服务体系、技术规格
/news/                  新闻动态    行业资讯、项目进展（CMS 可维护）
/cases/                 用户案例    场景化案例与证据摘录
/about/                 关于我们    使命、团队角色、生态伙伴、联系信息
/help/                  帮助中心    快速上手、FAQ、故障排查
/404                    错误页      迷路兜底 + 站点导航
/admin/                 内容后台    Token 登录、新闻/案例/FAQ 编辑、一键重建（不公开索引）
```

## 2. 信息架构与转化路径

**关键转化路径（≤3 次点击）**

- 路径 A（快速上手）：任意页 → 顶部导航「帮助中心」(1) → 快速上手步骤 (2) → 复制命令 (3)。首页 Hero 次级 CTA 直达帮助中心，仅 1 次点击。
- 路径 B（试点合作）：任意页 → 顶部导航「关于我们」(1) → 联系表单 (2) → 提交 (3)。首页/产品页底部 CTA「申请试点」锚点直达表单。
- 路径 C（看证据）：首页 Hero →「查看运行详情截图/案例」→ 案例详情锚点。

**全局导航**（桌面单行，7 项）：首页 · 项目介绍 · 产品与服务 · 用户案例 · 新闻动态 · 关于我们 · 帮助中心；右侧常驻「申请试点」主按钮。

## 4. 内容模型（CMS 数据）

```
src/data/news.json   [{ id, date(YYYY-MM-DD), category, title, summary, body[], featured? }]
src/data/cases.json  [{ id, industry, title, scenario, challenge, solution, metrics[], evidence }]
src/data/faq.json    [{ q, a }]
```

后台 `/admin` 以 Token 登录，编辑上述 JSON → 保存即触发 `build.js` 重建 → 静态页面即时生效。新闻页同时生成 `NewsArticle` JSON-LD，FAQ 生成 `FAQPage` JSON-LD。

## 5. 技术架构

```
src/pages/*.html      页面骨架（{{tokens}} 占位）
src/partials/*.html   head / header / footer 公共片段
src/data/*.json       内容数据
src/icons/*.svg       Phosphor 图标源 ──┐
assets/               CSS / JS / 截图 / 品牌资产 ──┤→ build.js → dist/
build.js              零依赖构建：片段拼装 + 内容渲染 + 图标雪碧图 + sitemap/robots
server.js             零依赖 Node 服务：静态托管 + 安全响应头 + /admin CMS + 重建 API
deploy/               Caddy / nginx HTTPS 配置样例 + systemd 单元
```

- **性能预算**：单页 HTML ≤ 40KB、CSS ≤ 35KB、JS ≤ 10KB（defer）、系统字体零请求、图像除首屏截图外全部懒加载。
- **SEO**：每页独立 title/description/canonical/OG；JSON-LD（Organization、WebSite、SoftwareApplication、FAQPage、NewsArticle、BreadcrumbList）；`sitemap.xml` 由构建自动生成（含 lastmod）。
- **无障碍**：WCAG 2.1 AA，语义地标、跳转链接、焦点可见、手风琴/导航 ARIA、`prefers-reduced-motion` 降级。
- **安全**：CSP（`default-src 'self'`）、HSTS（反代终止 TLS）、X-Content-Type-Options、Referrer-Policy、后台 Token 鉴权 + 登录限速。
