# 03 视觉设计规范（Design System）

> Veriforge 官方网站 · 设计系统文档 · 2026-10-06

## 0. 设计判读（Design Read）

> 面向工程技术决策者的 B2B 开发者工具官网；深色锻造工程语言（Dark Forge Engineering）；原生 CSS 实现以呼应产品"零框架"的技术气质；克制动效。

**设计拨盘**：`DESIGN_VARIANCE 5`（工程秩序感，非对称但不凌乱）· `MOTION_INTENSITY 4`（CSS 过渡 + IntersectionObserver 显现，尊重 reduced-motion）· `VISUAL_DENSITY 5`（保留数据密度：真实指标、等宽数字）。

品牌基因来源：Veriforge 官方应用图标（六边形锻印 + 熔钢渐变对勾 + 火花）与控制台设计系统（四层表面 + 状态色）。官网是控制台视觉的对外延展，二者同源。

## 1. 色彩体系

| Token | 值 | 用途 |
| :--- | :--- | :--- |
| `--bg` | `#090d12` | 全站画布（页面主题锁定为深色，不中途反转） |
| `--surface-1/2/3` | `#0c1117` / `#111820` / `#151e28` | 侧栏 / 卡片 / 浮起面板（四层表面体系） |
| `--line` / `--line-strong` | `#26313d` / `#34404d` | 发丝分隔线 / 强边框 |
| `--text` | `#eef2f6` | 主文本（对 `--bg` 对比度 ≈ 15.9:1，AAA） |
| `--muted` / `--subtle` | `#98a2ae` / `#6f7a87` | 次级 / 弱化文本（muted 对 bg ≈ 7.4:1 AA+） |
| `--accent` | `#ff7a1f` | 唯一强调色：熔钢橙（CTA、链接、高亮；对 bg ≈ 6.0:1） |
| `--accent-2` | `#ffc46a` | 渐变端色（仅用于品牌渐变与图表） |
| `--info` / `--ok` / `--warn` / `--danger` | `#8fb3ff` / `#7dcc9a` / `#e6bb76` / `#e58989` | 语义状态（与控制台一致） |

**品牌渐变（熔钢）**：`linear-gradient(135deg, #f4581c, #ff8c2e 38%, #ffc46a 74%, #ffedcf)`，仅用于 Logo 印章、关键数字与一条 Hero 装饰光带。禁止大面积渐变背景、禁止 AI 紫蓝光晕。

**单一强调色纪律**：全站唯一的交互强调色是熔钢橙；蓝/绿/黄/红只表达语义状态，不作装饰。

## 2. 字体系统

| 层级 | 字族 | 字号（clamp） | 行高/字距 |
| :--- | :--- | :--- | :--- |
| Display | 系统黑体栈（中文优先：PingFang SC / Microsoft YaHei） | `clamp(2.4rem, 5vw, 3.6rem)` | 1.08 / -0.02em |
| H2 | 同上 | `clamp(1.6rem, 3vw, 2.1rem)` | 1.15 / -0.015em |
| H3 / 正文 | 同上 | 1.15rem / 1.06rem | 1.6 |
| 数据 / 代码 / 指纹 | `ui-monospace, SFMono-Regular, Consolas` | 0.85–1rem | 1.5 |

零 Webfont 请求；中英文混排以系统中文字体渲染，等宽字体承载一切"机器事实"（commit、命令、指标），形成"人话 + 机话"的层次。

## 3. 几何与层次

- **圆角体系（唯一规则）**：输入/小按钮 8px；卡片/按钮/面板 10px；大区块 14px；徽章为全圆 pill。禁止混用其他圆角。
- **边框优先**：表面用 1px `--line` 发丝线分层，阴影仅在浮层使用且色调偏蓝黑（`rgba(0,0,0,.28)`），不用纯黑阴影。
- **间距**：4px 基数；区块纵向 `clamp(64px, 9vw, 112px)`；内容列 `min(1120px, 92vw)` 居中。
- **层次**：Canvas → Surface-1 → Surface-2 → Surface-3 四层，与控制台一致。

## 4. 组件库清单

`btn`（primary / ghost / 外链）、`chip`（分类徽章 pill）、`card`（含热感应 hover 抬升 2px）、`stat`（大号等宽数字 + 标签）、`timeline`（发展历程竖线节点）、`ladder`（验证阶梯图）、`table`（优势对照，sparse 分隔线）、`accordion`（FAQ，`aria-expanded`）、`tabs`（帮助中心命令切换）、`field`（表单：标签在上、错误在下、焦点环 3px `--focus`）、`nav`（桌面单行 + 移动抽屉）、`footer`、`kbd`、`codeblock`（命令行窗口样式）。

所有交互组件满足：`:focus-visible` 3px 焦点环、`:active` 下沉 1px、对比度 AA、键盘可达。

## 5. 动效规范

| 动效 | 实现 | 动机 |
| :--- | :--- | :--- |
| 进场显现 | IntersectionObserver 添加 `.in`，仅 `opacity` + `translateY(16px)`，0.55s | 叙事节奏：按阅读顺序揭示 |
| 卡片 hover | `translateY(-2px)` + 边框提亮 | 反馈可点性 |
| Logo 火花 | Hero 印章静态热辉（不循环闪烁） | 品牌记忆点 |
| reduced-motion | `@media (prefers-reduced-motion: reduce)` 下全部动画/过渡时长归零 | 无障碍硬性要求 |

禁止：滚动监听逐帧动画、循环脉冲、视差、自定义光标、marquee。

## 6. 图像与图标

- **图标**：Phosphor Icons（regular，1.5px 统一描边），构建期拼装为单文件 SVG 雪碧图（`/assets/img/icons.svg`），`<use>` 引用继承 `currentColor`。不手绘图标。
- **产品截图**：直接使用真实控制台截图（`console-run-detail.png`、`console-evidence.png`），装在带发丝边框的"窗口"容器中；禁止 div 假截图。
- **生态 Logo**：Simple Icons 官方路径本地化（单色 `#eef2f6`），仅 Logo 不加类别标签。
- **装饰**：仅两处品牌装饰：Hero 熔钢光带、CTA 横幅热辉渐变，均为低透明度背景层。

## 7. 文案语调

工程语言、动词开头、数据来自仓库事实（5 阶验证、450+ 用例、4 个运行时依赖）；中文为主，术语保留英文原词（Harness、Worktree、Runtime）；禁用空洞修饰词；全站不使用长破折号。
