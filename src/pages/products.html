首页 产品与服务

一个 Harness，五个子系统，从任务进来到 PR 回去。

开源社区版覆盖全部核心能力；企业服务面向私有化部署与试点陪跑。所有功能单机即可运行，SQLite 之外零中间件。

执行与裁决分离的架构

自然语言需求经采集引擎编译为冻结契约；Worker 在隔离工作区执行；Harness 全程持有状态、预算与验证；完成即证据落库，交付管道异步接力。

确定性状态机（FSM）

INIT 到 READY_FOR_REVIEW 的每一步都由强类型合法迁移表驱动。FAST_VERIFY 失败只能进 REPAIR，永远无法越级到完成；终态不可逆，进程崩溃后以全新 runId 恢复。

防篡改验证引擎

BASELINE / FAST / FULL 三级阶梯控制验证成本；PROTECTED 阶段强制恢复 Base Commit 原始测试；SYNTHESIZE 以 RED/GREEN 双向验证新测试的有效性。弱化检测器静态扫描 .skip、.only 与断言删除。

多 Runtime 与模型路由

Codex CLI 与 Claude Code 通过统一异步事件流契约接入，启动前自动能力探测，跨平台进程树终止保护。ModelRouter 按任务复杂度打分调度模型，超成本预算硬停机。

生产控制平面

SQLite 租赁队列免中间件实现分布式调度，心跳续租防抢占，磁盘水位准入；Transaction Outbox 保证终态与交付请求原子落库，GitHub PR 幂等创建并精确比对 CI headSha。

安全与可观测

默认回环绑定，RBAC Token 鉴权，Webhook HMAC 验签防重放，出网 URL Guard 拦截 SSRF 与 DNS 重绑定；事件存储只增不改，在线 WAL 热备份带完整性检查。

需求采集闭环

自然语言对话澄清需求，人工确认锁定后服务端编译为不可变契约；启动运行只传需求 ID，客户端无法中途篡改代码路径与安全规则。
