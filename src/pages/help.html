五分钟，看到第一条完整的验证链。

从克隆到控制台，四步完成。整个过程不调用任何外部模型服务，Scripted Runtime 在本地确定性执行。

快速上手

环境要求：Node.js 22.13 至 24、pnpm 10+、Git 2.30+。

克隆并安装

获取仓库并安装依赖，全部构建在本地完成。

terminal 
$ git clone <repo-url> && cd NANOFACTORY && pnpm install && pnpm build

运行端到端演示

内置一个带增值税缺陷的演示工程。脚本会构建真实 Git Worktree、执行验证阶梯并输出完整状态机轨迹，约 6 秒结束。

terminal 
$ pnpm demo

打开控制台

在可视化界面查看需求采集、运行轨迹、证据与审计，默认监听 127.0.0.1:7788。

terminal 
$ pnpm web  # 然后访问 http://127.0.0.1:7788

接入真实模型

把演示工程换成你的任务契约，用 --runtime codex 或 --runtime claude-code 驱动真实模型。契约字段、预算与验证命令见示例文件。

terminal 
$ node dist/cli/run-task.js run examples/task.example.json --runtime codex --json

故障排查

任务被标记为 BLOCKED

同一失败指纹连续 3 次无进展即熔断。用 veriforge inspect <runId> --events 查看时间线与指纹，确认是否为既有失败（preExisting）或路径策略违规。

BUDGET_EXCEEDED 太频繁

调高契约中的 maxIterations 与 maxRuntimeMinutes，或用 FAST 检查更快的子集命令。先看验证命令耗时分布再调预算。

控制台无法访问

服务默认只绑定回环地址。远程访问必须显式启用非回环绑定并配置角色 Token，TLS 交给反向代理（见部署文档）。

数据库维护

用 db backup 在线热备份、db check 校验完整性、db prune 清理超过保留期的只增历史。清理前先 --dry-run。
